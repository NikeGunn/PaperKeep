# Code of Conduct

Paperkeep is an open and respectful project space. We expect all participants to keep interactions constructive and professional.

Our standards
- Be respectful and inclusive
- Focus on the work, not the person
- Assume good intent and ask clarifying questions
- Keep discussions relevant and actionable

Unacceptable behavior
- Harassment, discrimination, or threats
- Spamming, trolling, or inflammatory language
- Sharing private information without consent

Scope
This code of conduct applies to GitHub issues, pull requests, and all project communications.

Enforcement
If you experience or witness unacceptable behavior, email: knewboy.nykhil@gmail.com

We may remove content or restrict participation when these guidelines are violated.
