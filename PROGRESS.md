### Phone-validated stability hotfix (2026-04-26 evening)

The "post-P3.15 stability" fixes above were green on JVM tests but failed on the user's physical phone (Android 15, OPPO CPH2423). On-device logcat with new `DebugLog` checkpoints provided ground truth:

- Save pipeline worked correctly (`Paperkeep.Capture` showed encrypted writes ~520KB image + 18KB thumb).
- `Paperkeep.Library` observed all 8 docs with correct thumb paths.
- **No `Paperkeep.Coil` decode lines ever fired** → Coil's default File fetcher was matching `.enc` files before our `EncryptedImageFetcher.Factory`, silently failing to decode AES-GCM ciphertext as JPEG. Every thumbnail blank.
- Edge detector returned `result=NotFound` on a real photo (2448×3264) → fallback inset quad fired every time, hence "auto-detect doesn't work".
- Handle drag was reading absolute `change.position` against a `(x - halfHandlePx)` value captured in a stale lambda closure, so handles drifted relative to the finger and shook on each recompose.

Fixes shipped:

- [x] **Bypass Coil for encrypted images:** new `EncryptedImage` composable in `:core:data` does AES-GCM decrypt + `Image(bitmap)` directly on `Dispatchers.IO`. Hilt entry-point retrieval guarded so Robolectric tests still render placeholder. Replaces `AsyncImage` in `DocumentCard` and `ReaderScreen.ZoomablePage`. Adds `:core:ui → :core:data` dep (pragmatic; documented).
- [x] **Drag uses image-space deltas:** `CornerHandle` now reports `dragAmount` per pointer event (no absolute-position closure capture); parent maps screen→image via `screenDeltaToImageDelta` and applies to current corner. `rememberUpdatedState` ensures latest callback without re-installing `pointerInput` mid-gesture.
- [x] **Disable destructive Room migration in debug:** removed `fallbackToDestructiveMigration(dropAllTables = true)` from `DataModule`. Older docs no longer wiped on every reinstall.
- [x] **DebugLog scaffolding:** new `DebugLog` in `:core:common`, gated on `FLAG_DEBUGGABLE`, no-op in release. Wired at `PaperkeepApplication.onCreate`. Three pipeline tags emit: `Paperkeep.Capture`, `Paperkeep.Library`, `Paperkeep.EncryptedImage`.
- [x] **Pre-existing test fix:** `P110CropVerificationTest.onQuadUpdated_persistsNewQuad` had off-by-one bounds (used 490 against a 400-tall bitmap); updated to 390. Was failing before this session's changes.
- [x] **Tests:** full `./gradlew testDebugUnitTest` BUILD SUCCESSFUL across 566 tasks; `:app:assembleDebug` BUILD SUCCESSFUL.

**Known remaining gap (not fixed this session):** `OpenCvEdgeDetector` is a luminance heuristic, not real OpenCV — fails on real-world photos with cluttered backgrounds. Auto-edge-snap will require either (a) actual OpenCV `findContours` integration or (b) accepting that the inset-quad fallback IS the auto-detect for v2. Tracked but out of scope for this hotfix.

## PHASE 4 — Local Backup, Storage Manager, Deep Polish

> **Spec:** `docs/PAPERKEEP_DESIGN.md` §5 (Phase 4)
> **Depends on:** Phase 3 complete
> **Goal:** Replace the dead cloud-sync value prop with a backup experience so good users don't miss the cloud. A11y + i18n + widgets.

- [x] **P4.1** — `:core:backup` module. **Completed 2026-04-27.** New `:core:backup` module wired in `settings.gradle.kts` with Hilt+KSP+kotlinx-serialization. SAF integration via `SafBackupGateway` / `ContentResolverSafGateway` (`ACTION_CREATE_DOCUMENT` / `ACTION_OPEN_DOCUMENT`, persistable URI permissions). KDF: `BackupKdf` runs Argon2id (`de.mkammerer.argon2-jvm:2.11`, `Argon2Factory.ARGON2id`) with production params m=128 MiB / t=4 / par=4 / 32 B salt / 32 B key — raw key material zeroed after wrap into `SecretKeySpec`. Cipher: `BackupCipher` streams `AES/GCM/NoPadding` (12 B IV, 128-bit tag) via `CipherOutputStream` / `CipherInputStream`. Wire format: 62-byte plain header `PKBK | u16 version | u32 memKib | u32 iter | u32 par | 32 B salt | 12 B IV` then GCM ciphertext containing the inner ZIP. Engine = `BackupEngine.write/read` + `BackupReadVisitor`. Zip4j intentionally NOT used (whole-stream GCM + manifest SHA-256 is stronger than per-entry ZIP encryption). `BackupHeaderTest` (10 tests) + `BackupEngineTest` (6 tests, reduced KDF params for speed) cover roundtrip, bad magic, unsupported version, wrong password, tampered ciphertext, fresh salt+IV per backup, manifest SHA-256 parity.
- [x] **P4.2** — Backup contents + `BackupEntity`. **Completed 2026-04-27.** `BackupManifest` (`@Serializable`, `format="paperkeep.backup"`, schemaVersion=1, `createdAtMs`, app version, `documentCount`, `pageCount`, `pages: List<PageRef>` with `zipPath / documentId / pageId / pageIndex / sha256 / sizeBytes`, `ignoreUnknownKeys=true` for forward-compat). ZIP entry order: `manifest.json` (DEFLATED) → `paperkeep.db` (DEFLATED, raw bytes from `context.getDatabasePath`) → `settings.json` (DEFLATED) → `pages/<docId>/<pageIndex>.jpg` (STORED, decrypted from on-device AES-GCM, then re-encrypted under the backup password's separate key — backups are portable, NOT bound to K_master). `BackupEntity` (`@Entity(tableName="backups", indices=[Index("createdAt")])`) + `BackupDao` + Room v7→v8 `MIGRATION_7_8` (additive `CREATE TABLE backups` + index). `BackupCoordinator.runBackup` writes a row with persistable SAF URI on success. Tests cover manifest roundtrip, manifest unknown-key tolerance, settings roundtrip.
- [x] **P4.3** — Password strength meter. **Completed 2026-04-27.** `PasswordStrengthMeter` is a from-scratch local implementation — zxcvbn-kotlin / libsodium are banned by `CLAUDE.md`. `MIN_LENGTH=10`, score enum + `Estimate(score, bitsOfEntropy, meetsMinimumLength, warnings)`. Bit estimate = `len * log2(poolSize)` with subtractive penalties for COMMON list hits, keyboard RUNS, repeated characters, missing class diversity. Used inline in `CreateBackupDialog` via `LinearProgressIndicator(progress = { pct })` + warning text. `PasswordStrengthMeterTest` (10 tests).
- [x] **P4.4** — Backup reminders. **Completed 2026-04-27.** `BackupReminderCadence` enum (NEVER / WEEKLY / MONTHLY) persisted via `BackupReminderPrefs` (DataStore Preferences). `BackupReminderScheduler` uses `AlarmManager.setInexactRepeating(RTC_WAKEUP, …)` + `PendingIntent.FLAG_IMMUTABLE | FLAG_UPDATE_CURRENT` — deliberately NOT `SCHEDULE_EXACT_ALARM` (Play sensitive permission, inexact is fine for "remember to back up"). `BackupReminderReceiver` (`exported=false`, registered in `:app`'s `AndroidManifest`) ensures channel `paperkeep.backup_reminders` and posts `NotificationCompat` with launcher PendingIntent; checks `POST_NOTIFICATIONS` on API 33+ and silently skips if denied. `POST_NOTIFICATIONS` permission added to manifest with comment about runtime prompt. `BackupReminderCadenceTest` (5 tests) covers `fromKey` defaults + interval math.
- [x] **P4.5** — Restore flow. **Completed 2026-04-27.** `BackupCoordinator.runRestore(sourceUri, password, strategy)` reads the envelope via `BackupEngine.read` + `BackupReadVisitor` (manifest → DB bytes ignored at runtime for safety → settings → pages). Per-page SHA-256 is verified against the manifest *after* GCM auth — catches decrypt-then-rezip-then-resign tampering that GCM cannot detect because the outer envelope tag still validates. `RestoreStrategy.MERGE` keeps existing rows; `RestoreStrategy.REPLACE` wipes documents/pages first. Restored docs land in a `"Restored YYYY-MM-DD"` folder.
