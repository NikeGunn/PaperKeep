FULL DESCRIPTION  (4 000 chars max)
--------------------------------------------------------------------------
Paperkeep is the document scanner that keeps everything on your phone.
No account required. No cloud upload. Just fast, private scanning.

── SMART CAPTURE ──────────────────────────────────────────────────────────
Real-time edge detection finds document corners automatically. Tap to
capture — Paperkeep warps the perspective, trims the borders, and delivers
a flat, print-ready scan in under a second.

Five specialised modes for every document type:
  • Document (A4/Letter) — crisp, searchable output
  • Receipt — tall crop, aggressive B&W, extracts total/date/merchant
  • ID Card — front + back auto-composed on one A4 page
  • Whiteboard — glare removal, marker colour boost, shadow removal
  • Book Scan — two-page spread auto-split, spine flattening

── SEARCH EVERYTHING ──────────────────────────────────────────────────────
On-device OCR (powered by ML Kit) reads every word in every scan. Search
finds results inside documents, not just by filename. All OCR text is
encrypted — the search engine never sees plaintext on disk.

── EXPORT ANYWHERE ────────────────────────────────────────────────────────
  • PDF with invisible, selectable text layer
  • JPEG / PNG per page
  • Encrypted ZIP for secure transfer (Argon2id key derivation)
  • Share via any app — WhatsApp, Gmail, Drive, Dropbox

── PROFESSIONAL TOOLS ─────────────────────────────────────────────────────
  • Image filters: Original · Auto · Magic Color · Grayscale · B&W
  • Signature tool — draw, save up to 3 signatures, place on any PDF page
  • Text annotations and highlights with 30-step undo/redo
  • Destructive redaction — permanently blacks out pixels and OCR text
  • Image cleanup — remove background noise, sharpen text, fix lighting

── PRIVACY BY DESIGN ──────────────────────────────────────────────────────
  • AES-256-GCM encryption for every file on disk
  • Biometric app lock (fingerprint / face) with short timeout
  • FLAG_SECURE on every screen showing document content
  • No analytics SDK. No crash reporter. No telemetry. Ever.
  • Data Safety declaration: no data collected.

── ORGANISED ─────────────────────────────────────────────────────────────
  • Folders with auto-rules (e.g. receipts auto-sort to Receipts folder)
  • Colour tags, favourites, archive
  • Two-column / four-column library grid

AdMob interstitials are shown after every 5th export (max once per 3 min).
EU users see a GDPR consent prompt before any ad loads.
Paperkeep Pro (coming soon) removes all ads.
