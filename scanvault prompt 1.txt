AWS CREDENTIALS SETUP (one-time, done by human before running Claude Code):
  Human steps (you do these manually before starting):
  1. AWS Console → IAM → Create user "scanvault-deploy"
  2. Attach policy: PowerUserAccess + IAMFullAccess (or a scoped custom policy)

       [scanvault]
       aws_access_key_id = AKIA...
       aws_secret_access_key = ...
  4. aws configure --profile scanvault  (or set AWS_PROFILE=scanvault)
  5. Confirm: aws sts get-caller-identity --profile scanvault → should return your account ID

Claude Code will use AWS_PROFILE=scanvault for all Terraform and AWS CLI commands.
